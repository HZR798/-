# 个人博客项目

这是一个使用纯HTML、CSS和JavaScript构建的个人博客网站，展示了前端工程化的最佳实践。

## 🚀 技术栈

- **HTML5**: 语义化标签和结构
- **CSS3**: 现代CSS特性，包括CSS变量、Flexbox、Grid、动画
- **JavaScript (ES6+)**: 模块化、类、异步编程
- **Parcel**: 零配置的Web应用打包工具

## 🛠️ 工程化特性

### 1. 模块化开发
- 使用ES6模块系统组织JavaScript代码
- CSS变量实现主题系统
- 组件化的HTML结构

### 2. 自动化构建
- Parcel自动处理资源打包和优化
- 热重载开发服务器
- 生产环境代码压缩和优化

### 3. 响应式设计
- 移动优先的响应式布局
- CSS Grid和Flexbox布局系统
- 适配不同屏幕尺寸

### 4. 用户体验优化
- 暗色主题切换
- 平滑滚动导航
- 交互动画效果
- 本地存储主题偏好

### 5. 代码质量
- 语义化HTML结构
- CSS方法论（BEM风格）
- JavaScript最佳实践

## 📁 项目结构

```
src/
├── index.html          # 首页
├── blog.html           # 博客列表页
├── posts/              # 文章页面
│   └── post1.html
├── css/
│   └── style.css       # 主样式文件
├── js/
│   └── main.js         # 主JavaScript文件
└── assets/             # 静态资源
```

## 🏃‍♂️ 运行项目

### 开发环境
```bash
npm run dev
```
启动开发服务器，支持热重载。

### 生产构建
```bash
npm run build
```
构建优化后的静态文件到`dist`目录。

### 预览生产版本
```bash
npm start
```
构建并启动本地服务器预览生产版本。

## 🎨 设计特色

- **现代化UI**: 使用渐变背景和卡片式设计
- **动画效果**: CSS动画和JavaScript驱动的交互动画
- **主题系统**: 支持亮色和暗色主题切换
- **无障碍设计**: 考虑键盘导航和屏幕阅读器

## 📱 功能特性

- 响应式导航栏
- 博客文章列表
- 文章详情页面
- 主题切换功能
- 平滑页面滚动
- 交互动画效果

## 🔧 开发工具

- **Parcel**: 快速的零配置打包工具
- **npm scripts**: 自动化构建和开发任务
- **ESLint**: 代码质量检查（可扩展）
- **Prettier**: 代码格式化（可扩展）

## 📈 性能优化

- CSS变量减少重复代码
- 模块化JavaScript减少初始加载时间
- 优化的图片加载（懒加载可扩展）
- 压缩的构建输出

这个项目展示了如何在不使用大型框架的情况下，通过现代Web标准和工具构建高质量的前端应用。
